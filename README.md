# Tobacco Counter (Cigarette Counter) - Flutter Version

This is the Flutter migration of the original Android application.

## 📱 Features (Planned/Implemented)
- **Cigarette Counting**: Track each cigarette smoked.
- **Cost Tracking**: Calculate total spending.
- **Home Screen Widget**: Quick access to count.
- **Analytics**: Statistics and charts.
- **Health Insights**: Cancer risk and Brinkman index.

## 📂 Project Structure
- `/lib`: Flutter source code.
- `/android_native`: Legacy native Android project (archived).

## 🚀 Getting Started

### Prerequisites
- Flutter SDK
- Android Studio / VS Code

### Running
```bash
flutter run
```

## 🏗️ Architecture
- **State Management**: Provider
- **Database**: SQLite (sqflite)
- **Charts**: fl_chart
- **Widget**: home_widget

For the original Android documentation, see [android_native/README.md](android_native/README.md).
